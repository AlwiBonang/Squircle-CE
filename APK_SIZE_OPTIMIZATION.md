# APK size optimization

The project already enables R8 minification and resource shrinking for the `release` build type in the application convention plugin.

## Recommended builds

- Universal/debug APK: `./gradlew assembleGmsDebug`
- Optimized release: `./gradlew assembleGmsRelease`
- For a smaller install/download, use the ABI-specific APK generated by ABI splits (for example `arm64-v8a` on most modern Android phones), rather than the universal APK.

ABI splits are enabled in `app/build.gradle.kts` and a universal APK is retained for convenience. The release build uses R8 and resource shrinking; debug builds are not expected to be as small as release builds.

Do not remove ICU, editor grammars, or native libraries blindly: they may be required by language processing, syntax highlighting, or runtime features.
